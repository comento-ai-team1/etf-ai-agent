# ETF AI 상담센터

> **ETF 질문을 이해하고, 공개 자료의 출처와 기준일을 확인해 답하는 챗봇**

코멘토 AI 에이전트 개발 부트캠프 2주차 개인 시제품입니다. 한국투자신탁운용의 내부 자료는 제공받지 않았으며, **공개 API와 공개 자료 기반 샘플 데이터**로 구현합니다.

현재는 ETF 시세와 DART 공시를 조회하는 챗봇이 동작합니다. 다음 단계에서는 작은 SQLite DB를 만든 뒤, LangChain 에이전트가 DB와 기존 API를 도구로 사용하도록 확장합니다.

## 🎯 프로젝트 소개

| 항목 | 내용 |
| --- | --- |
| 서비스명 | ETF AI 상담센터 |
| 목적 | ETF 입문 질문과 상품 정보 질문에 근거 있는 답변 제공 |
| 사용자 | ETF를 처음 접하거나 상품 정보를 확인하려는 투자자 |
| 데이터 | 공개 ETF 시세 API, DART 공시, 공개 상품 정보·FAQ 샘플 |
| 화면 | Streamlit 기반 웹 챗봇 |
| 2주차 목표 | 작은 상품·FAQ DB와 LangChain 도구 호출까지 시연 |

### 핵심 원칙

- 확인한 자료의 **출처와 기준일**을 함께 보여줍니다.
- 조회되지 않은 가격·수익률·공시 내용은 만들어내지 않습니다.
- 공개 자료로 만든 시제품을 고객사의 **내부 DB 연동 서비스로 표현하지 않습니다.**

## 🗺️ 주요 기능과 현재 상태

| 기능 | 현재 상태 | 설명 |
| --- | --- | --- |
| 질문 분류 | ✅ 구현 | OpenAI API로 시세·공시·FAQ·지원 불가 질문을 구분 |
| ETF 시세 조회 | ✅ 구현 | 지원 상품 2개의 자료 기준일 종가·NAV 조회 |
| DART 공시 조회 | ✅ 구현 | 상품명이 일치하는 공시 후보의 제목·날짜·원문 링크 표시 |
| 조회 자료 검증 | ✅ 구현 | 상품명·날짜·수치·출처·공시 링크 확인 |
| 응답 시간 기록 | ✅ 구현 | 질문별 응답 시간을 CSV에 저장 |
| 상품 기본정보 DB | ⬜ 예정 | 공개 자료로 10~20개 상품의 샘플 DB 구축 |
| FAQ 검색 | ⬜ 예정 | 검토한 FAQ 20~30개를 저장하고 관련 항목 검색 |
| LangChain 에이전트 | ⬜ 예정 | 상품 DB·FAQ·ETF API·DART를 도구로 연결 |
| 최종 답변 검토 | ⬜ 예정 | 답변의 출처·기준일·유의 문구 확인 |

현재 조회 가능한 시세 상품은 **KODEX 200**, **KODEX 인도Nifty미드캡100**입니다. 시세는 실시간 가격이 아닌 **표시된 자료 기준일의 종가**입니다. DART 기능은 **공시 제목 수준의 후보 검색**이며 공시 본문을 요약하지 않습니다.

## 🤖 AI 활용 방식

| 역할 | 현재 방식 | 다음 단계 |
| --- | --- | --- |
| 질문 해석 | OpenAI API를 호출하는 Python 오케스트레이터 | LangChain 에이전트의 도구 선택으로 연결 |
| ETF 설명 | 조회한 시세를 OpenAI API에 전달 | 상품 DB·시세 API 결과를 근거로 사용 |
| FAQ 답변 | LLM의 일반 설명 | 검토된 FAQ를 먼저 검색해 근거로 제공 |
| 자료 확인 | ETF·DART 조회 결과의 필수 항목 검사 | 생성된 최종 답변도 확인 |

**현재는 LangChain과 CrewAI를 사용하지 않았습니다.** 2주차에는 LangChain을 선택해 기존 조회 함수를 실제 도구로 등록합니다. 금융 언어 모델의 추가 학습·미세조정은 시제품 범위에 포함하지 않습니다.


```text

                     ├─ 상품 DB 조회 도구
                     ├─ FAQ 검색 도구
                     ├─ ETF 시세 API 도구
                     └─ DART 공시 도구
                   → 자료·답변 확인 → 출처·기준일을 포함한 응답
```

## 🚀 로컬 실행

### 1. API 키 설정

프로젝트 루트의 `.env`에 다음 항목을 저장합니다. 실제 키 값은 README나 제출 파일에 적지 않습니다.

```text
OPENAI_API_KEY=발급받은_키
ETF_DATA_API_KEY=발급받은_키
DART_API_KEY=발급받은_키
```

### 2. 패키지 설치

이미 가상환경을 만든 경우, VS Code 터미널에서 프로젝트 폴더로 이동해 설치합니다.

```powershell
cd C:\eft_chatbot_demo
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

LangChain 단계에 도달하면 `langchain`과 `langchain-openai`를 추가로 설치하고 `requirements.txt`에도 기록합니다.

### 3. 챗봇 실행

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

터미널에 표시된 **Local URL**을 엽니다. 포트가 달라질 수 있으므로 브라우저가 실제로 연 주소를 확인합니다.

## 📊 샘플 DB 구축 계획

Python 기본 기능인 `sqlite3`로 시작합니다. 외부 자료를 저장할 때는 **출처 URL과 자료 기준일 또는 확인일을 함께 저장**합니다.

| 테이블 | 저장할 내용 | 최초 확인 규모 |
| --- | --- | --- |
| `etf_products` | 종목코드, 상품명, 운용사, 기초지수, 총보수, 기준일, 출처 URL | 기존 지원 상품 2개 |
| `faq` | 질문, 검토한 답변, 주제, 확인일, 출처 URL | FAQ 5개 |

처음에는 작은 데이터로 **저장 → 검색 → 답변에 전달**되는 흐름을 확인합니다. 이후 멘토님이 제안한 규모인 **상품 10~20개, FAQ 20~30개**로 확장합니다. 예상 고객 질문은 실제 VOC라고 부르지 않고, 별도의 **평가용 질문 목록**으로 관리합니다.

## ✅ 시연 질문

| 질문 | 기대 결과 |
| --- | --- |
| `ETF와 주식은 어떻게 달라?` | 검토된 FAQ 자료를 바탕으로 쉬운 설명 |
| `KODEX 200의 종가와 NAV를 알려줘` | 기준일·종가·NAV·출처 표시 |
| `KODEX 200의 종가와 관련 공시를 같이 알려줘` | 시세와 DART 공시 후보를 함께 표시 |
| `달토끼 우주여행 ETF의 종가 알려줘` | 지원하지 않는 상품 안내, 가격 생성 방지 |

첫 번째 질문의 **FAQ 자료 검색**은 앞으로 구현할 기능입니다. 나머지 질문은 현재 데모의 기능을 확인할 때에도 사용합니다.

## ⚠️ 데이터·답변 유의사항

- 본 서비스는 **공개 자료 기반 샘플 시제품**이며 고객사 내부 자료를 사용하지 않습니다.
- 기준일 종가를 오늘의 실시간 가격으로 표현하지 않습니다.
- 공시 검색 결과는 제목이 일치하는 **후보**이며, 변경 내용은 공시 원문에서 확인해야 합니다.
- 뉴스는 추후 사용하더라도 본문 전체를 저장하기보다 제목·요약·링크 중심으로 검토합니다.
- `.env`와 API 키는 공유·제출하지 않습니다.
